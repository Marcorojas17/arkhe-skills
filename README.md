# ARKHE SKILLS

Official skill collection for **ARKHE ZERO**, built from Termux on Android by Marco Antonio Rojas Valdovinos.

## Skills included

| Skill | Description | Verifiable? |
| :--- | :--- | :--- |
| `arkhe-video` | Forensic video generator with ffmpeg + SHA-256 + HMAC certification | ✅ Local verification |
| `arkhe-dream-real` | Dream interpretation with real neuroscience (no magical thinking) | ✅ Based on 859-symbol index |
| `arkhe-sentinel-shield` | Query live status of ARKHE SENTINEL MCP firewall | ✅ Via Render API |
| `arkhe-certify` | Generate SHA-256 authorship certificates for any file | ✅ Offline verify |

## Installation

### Claude Code
```sh
/plugin marketplace add Marcorojas17/arkhe-skills

npx skills add Marcorojas17/arkhe-skills --list
npx skills add Marcorojas17/arkhe-skills --skill arkhe-video
/add-plugin Marcorojas17/arkhe-skills
